# PROVENANCE RULES

## Source precedence is not simply version number
1. 当前明确 LOCKED 决定
2. ORIGINAL（作为原始语言资产保存）
3. SOURCE FACT（按来源与日期记录）
4. DRAFT / Working Draft
5. Historical structure
6. External reference

## Historical files
旧文件可以提供：
- 概念形成过程
- 已出现过的内容项
- 历史产品/课程/空间资料
- 用户旅程研究

但不能自动恢复：
- 旧导航
- 旧商店
- 旧 Homepage
- 未确认运营状态

## Duplicate files
同名或 `(1)/(2)` 的重复资料不重复计为多个事实；只登记 provenance，不人为增加权重。
