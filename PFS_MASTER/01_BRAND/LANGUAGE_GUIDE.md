# LANGUAGE GUIDE

## 🔒 NAMING — 2026-09-19

### PFS / 派对朋友的飞船
**派对朋友的飞船 = Party Friend Ship**

这是项目名称及其英文表达，不得改名、意译或自动替换为 `Spaceship`。
其中 `Party / Friend / Ship` 与既有表达“派对=乐趣；朋友=人、社交、网络；飞船=冒险、改变”共同作为 PFS 的命名/语言资产保存。

### PFS 建造学校
`PFS 建造学校` 是当前 PFS 场地主体的名称/概念。
不得因为历史资料中出现 `BUILDING CAMP`、`THE CAMP IS THE SCHOOL` 等表达，就擅自把项目或建造学校改名为 Building Camp。
`Building Camp` 只在其有明确来源和具体语境时作为历史/项目/活动表达保存。

### 大飞船
**大飞船 = The Spaceship**

`The Spaceship` 专指 PFS 场地中的“大飞船”空间节点。
不得用 `The Spaceship` 指代 PFS / 派对朋友的飞船整个项目。

### AI terminology guardrail
- PFS / 派对朋友的飞船 → `Party Friend Ship`
- 大飞船 → `The Spaceship`
- 不得互换。
- 不得因英文自然化而擅自改名。
- Building Camp / Building School 的历史英文表达不得反向改写 PFS 项目名称。

## 🔒 BRAND LANGUAGE EXTRACTION RULE — 2026-09-19
从 PFS 公众号、创始人原话、历史项目、产品文章、项目档案及官方旧网站提取品牌语言时：**Original Source → Preserve exact wording → Classify → Optional AI Draft**。先保存原话，不得由 AI 先“优化”再存入 Master。
- 确认为 PFS 已建立的原始表达 → 🟣 ORIGINAL。
- 只能确认曾出现在某份来源 → 🟢 SOURCE COPY / SOURCE FACT。
- AI 改写、总结、扩展 → 🟡 DRAFT。
- 经过明确确认的当前执行语言 → 🔒 LOCKED。

AI Draft 不得覆盖 Original。
