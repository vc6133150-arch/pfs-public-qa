# EXPERIENCE RELATIONSHIPS

> 用于防止 AI 把 PFS 建造学校拆成互不相关的业务栏目。

## 🔒 LOCKED
PFS 建造学校是主体；VISIT / STAY / BUILDING / SHOP / WORK WITH US 是用户进入这一主体的不同路径。

当前核心体验逻辑：**STAY → LIVE → BUILD｜停留 → 生活 → 建造**。
其中 BUILDING 是更大的行动概念：Learning（在建造过程中学习）、Making（在建造过程中制作）、Building Practice（进入真实建造实践），也包括对空间与材料的认识。
Learning / Making 归入 Building，不作为与 Building 平级的核心体验阶段。住宿、学习、制作、建造发生在同一真实场地与体验过程中，不拆成四种独立产品。
此处说明体验逻辑，不改变 Website 顶部导航或页面信息架构。

## 🟢 SOURCE FACT
现有资料支持以下体验关系：
- VISIT：认识场地、空间、展示与现场体验
- STAY：停留、生活、住宿，并与建造/课程/场地探索发生关系
- BUILDING：TRY / JOIN / COURSES / BUILD
- WHAT'S ON：把当前可参与内容与 Calendar 连接
- SHOP：把 PFS 产品、材料包/制作文化与带走 PFS 的体验连接
- WORK WITH US：志愿、空间使用、Venue Hire、P-CUT、Bring Your Idea、Build With PFS 等参与入口

这些关系用于内容组织，不意味着它们是六个平行业务公司。
